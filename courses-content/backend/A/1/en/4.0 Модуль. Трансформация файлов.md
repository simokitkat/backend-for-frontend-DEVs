# Module 4. File transformation

![Badge for the File transformation module](../../../public/a1-module-badges/04-file-transformation.svg)

Implement transformation of text files and images. Start from the shared contract, then add the formats and the limits for each kind of data.

## Learning objectives

After this module you will be able to:

- describe the shared contract for transforming a file;
- choose a library and check that the source and target formats are supported;
- handle limits on size, content, and parameters safely;
- put the transformation in a separate component and diagnose failures.
