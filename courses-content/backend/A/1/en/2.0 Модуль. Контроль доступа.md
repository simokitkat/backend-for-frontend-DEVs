# Module 2. Access control and user data

![Badge for the Access control and user data module](../../../public/a1-module-badges/02-access-control.svg)

In this module, set up access checks that run after authentication. Work through roles and permissions, then apply them when an owner and an administrator view user data.

## Learning objectives

After this module you will be able to:

- tell authentication apart from authorization;
- apply roles and a default deny;
- check the permission for an action and access to a specific user;
- handle forbidden requests correctly and observe them.
