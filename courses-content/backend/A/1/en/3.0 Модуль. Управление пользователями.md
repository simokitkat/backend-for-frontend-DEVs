# Module 3. User management

![Badge for the User management module](../../../public/a1-module-badges/03-user-management.svg)

Here you extend the user-management API: updating an account, deleting an account, and viewing the list. For repeated requests and auditing, rely on the theory from the previous modules.

## Learning objectives

After this module you will be able to:

- update user data safely, with a check for both the owner and an administrator;
- design deletion so that it accounts for related data and for repeated requests;
- implement a user list with filtering and pagination;
- add an audit trail and diagnostic information to management operations.
