# Module 1. User identification

![Badge for the User identification module](../../../public/a1-module-badges/01-identity.svg)

This module walks through creating an account and the first protected sign-in. Start with the data model and the architecture, then implement registration and authentication.

## Learning objectives

After this module you will be able to:

- design the user model and its constraints;
- explain the structure of a server application and how its parts interact;
- implement registration with safe handling of the password and of account confirmation;
- verify the user's identity at sign-in and issue tokens for later requests.
