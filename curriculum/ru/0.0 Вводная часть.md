# Front End Department / Back End Course / Group A1

## О чём курс

Обучение Back End для Front End-разработчиков нацелено на повышение компетенций с учётом актуальных требований рынка и формирование профиля T-Shaped (широкий кругозор с глубокой экспертизой в ключевой области).

> Задание является единым для всех участников, ***однако любая его часть может быть персонально скорректирована по согласованию с ментором.***
>

## Инструменты

Допускается использование любых инструментов, включая искусственный интеллект, на всех этапах реализации. При этом участник обязан быть готовым к полному и аргументированному обоснованию каждого принятого технического решения на промежуточных и финальном ревью с ментором. Если инструменты отличаются от рекомендуемых в задании, их необходимо согласовать с ментором.

## Менторы

Каждому участнику назначается ментор с учётом уровня его подготовки и локации.
Ментор каждую неделю собирает актуальный статус разработки практического задания.

> ***На любом этапе обучения участники могут обращаться к ментору за теоретическими и техническими консультациями.*** Для согласования встречи необходимо связаться с ментором и назначить время через календарь.
Кроме того, при нахождении в одном офисе с ментором можно обращаться напрямую оффлайн, без предварительного согласования.
> 

### Финальный результат

К концу курса получается backend-сервис: монолитное HTTP API с реляционной базой, проверкой доступа к операциям и фоновыми задачами. Отдельный фронтенд не нужен — все сценарии вызываются из HTTP-клиента.

Сервис регистрирует пользователей и при необходимости подтверждает email, выполняет вход с access- и refresh-cookie, управляет ролями и разрешениями и авторизует защищённые операции. Пользователь читает и изменяет профиль, удаляет учётную запись; администратор ведёт список пользователей, роли и чужие профили. Тот же сервис преобразует текстовые файлы и изображения, отдаёт историю операций и по запросу сохраняет результаты в объектное хранилище.

### Ресурсы

#### Node.js

> Boilerplate для старта нового монолитного проекта на NestJS.
> Содержит базовые модули и подключения.
> [https://github.com/pavel-skripko-innowise/nestjs-monolith-boilerplate](https://github.com/pavel-skripko-innowise/nestjs-monolith-boilerplate)

#### .NET

> Шаблон проекта для старта монолитного Web API на .NET Core.
> Содержит базовую конечную точку API `/health`, которая подтверждает, что сервис работает.
> OpenAPI включён в окружении Development.
> В настоящее время шаблон предоставляет только документ OpenAPI; интерфейс Swagger в него не входят.
> Тестовый проект использует xUnit и проверяет, что GET-запрос к `/health` возвращает 200 OK.
> [https://github.com/pavel-skripko-innowise/dotnet-minimal-webapi-boilerplate/](https://github.com/pavel-skripko-innowise/dotnet-minimal-webapi-boilerplate/)
